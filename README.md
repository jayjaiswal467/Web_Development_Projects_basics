# Web Development Projects & Basics

A collection of web development projects built while learning HTML, CSS, and JavaScript.

## Projects

### 1. CSS Sidebar Mini Project
A responsive sidebar navigation menu built using HTML and CSS.

**Features**
- Sidebar navigation
- Responsive layout
- Font Awesome icons
- Smooth transitions

**Technologies:** HTML5, CSS3

### 2. Shadow Hunter Profile
A profile webpage created using HTML and CSS.

**Technologies:** HTML5, CSS3

### 3. Simon Says Game
An interactive memory game built using HTML, CSS, and JavaScript. Players repeat an increasingly long sequence of colored buttons.

**Features**
- Random color sequence generation
- Interactive button animations
- Level progression
- User input validation
- Game-over and restart functionality

**Technologies:** HTML5, CSS3, JavaScript

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Git and GitHub
